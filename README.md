# Antigravity Usage & Speed Monitor (เวอร์ชันภาษาไทย)

เอกสารแนะนำและคู่มือการใช้งานปลั๊กอิน **Usage & Speed Monitor** สำหรับ **Google Antigravity App (Desktop)**

---

## 📌 บทนำ (Overview)

**Usage & Speed Monitor** คือปลั๊กอินตรวจวัดและแสดงผลประสิทธิภาพการทำงานของโมเดล AI ใน Antigravity App แบบเรียลไทม์ 100% ออฟไลน์ โดยไม่มีการส่งข้อมูลหรือพรอมต์ออกไปภายนอก

### จุดประสงค์หลัก
1. **ติดตามการใช้งาน Token และ Context Window:** ตรวจสอบขนาดบริบทที่ใช้งานไปเทียบกับขีดจำกัดสูงสุดของแต่ละโมเดลแบบละเอียด
2. **วัดความเร็วการตอบกลับ (Generation Speed):** แสดงผลความเร็วในการสร้างข้อความ (`tok/s`) และเวลาในการตอบสนองคำแรก (`TTFT` - Time to First Token)
3. **ติดตามโควต้าคงเหลือ (Quota Pools):** ตรวจเช็กโควต้าคงเหลือ เช่น โควต้า Gemini ราย 5 ชั่วโมง และรอบเวลารีเซ็ต
4. **คำนวณค่าใช้จ่ายเป็นเงินบาท (THB ฿):** แปลงค่าธรรมเนียมการประมวลผลตามตารางราคาจริงเป็นเงินบาทให้เห็นทันที

---

## 🚀 ฟีเจอร์สำคัญ (Core Features)

### 1. Capsule บนกล่องพิมพ์ (Composer Mount)
- ฝังแถบสถานะขนาดกะทัดรัด (Capsule) ไว้บนหรือชิดกับกล่องพิมพ์ข้อความ (Composer)
- แสดงตัวเลขทศนิยม 2 ตำแหน่งแบบ Tabular Numerals (ความกว้างตัวเลขนิ่ง ไม่สั่นไหว)
- สามารถเลือกแสดงผลได้ 1 หรือ 2 ช่อง หรือสลับตำแหน่ง ซ้าย ↔ ขวา
- มีแอนิเมชัน SVG หมุน 60fps ขณะที่ AI กำลังคิดและประมวลผล (`is-running`)

### 2. หน้าต่าง Popover ควบคุม 4 แท็บ
คลิกที่ Capsule เพื่อเปิดดูรายงานเต็ม:
- **เรียลไทม์ (Live):** ดูความเร็วปัจจุบัน, TTFT, จำนวนโทเคนของแชทปัจจุบัน
- **สถิติการใช้งาน (Consumption):** สรุปการใช้โทเคนแยกตามวัน สัปดาห์ และรอบโควต้า
- **รายละเอียด (Details):** จำแนก Token ออกเป็น 10 หมวดหมู่ (Prompt, System Prompt, Context Cache, Tool Calls, ฯลฯ) พร้อมตัวแยกระหว่าง Main Agent และ Subagents
- **การตั้งค่า (Settings):** ปรับแต่งธีม, ขนาดตัวอักษร, ภาษา (ไทย `th-TH` / อังกฤษ `en-US`), ตำแหน่ง Capsule และการเปิด/ปิดช่องแสดงผล

### 3. รองรับ Split View และ Multiple Windows
- ทำงานแยกกันอิสระในแต่ละหน้าต่างของ Split View
- แชทใหม่ที่ยังไม่ส่งข้อความจะแสดงสถานะเริ่มต้นที่ `0.00% Context` พร้อมดึงโควต้าหลักมาแสดงทันที

### 4. ปลอดภัยและทำงานในเครื่อง 100% (Zero-LLM & Offline)
- ไม่ใช้โมเดล AI เพิ่มเติมในการคำนวณสถิติ
- ไม่มีการดักจับข้อความหรือแก้ไขคำขอของระบบ
- บันทึกการตั้งค่าไว้ที่ `~/.gemini/antigravity/sidecar_data/usage-monitor/` บนเครื่องของคุณเท่านั้น

## 💡 วิธีเปิดใช้งานและคำแนะนำการใช้งาน

### 1. การเปิดใช้งานครั้งแรก
1. เปิด Antigravity App แล้วตรวจสอบที่หน้าการตั้งค่า [usage-monitor](customization://usage-monitor) ว่าสถานะเปิดอยู่ (`Enabled`)
2. บน Windows: ปลั๊กอินจะตั้งค่าอาร์กิวเมนต์ที่จำเป็นสำหรับตรวจวัดผ่าน Shortcut ให้อัตโนมัติ
3. ปิดแล้วเปิด Antigravity App ใหม่ 1 ครั้งเพื่อให้ Sidecar Capsule ติดตั้งลงบนแถบ Composer อย่างสมบูรณ์

### 2. วิธีสั่งการและควบคุม
- **ชี้เมาส์ (Hover):** แสดงสรุป Context Window และ Quota Pool ด่วน
- **คลิกซ้าย:** เปิดกล่อง Popover แสดงรายละเอียด 4 แท็บ
- **คลิกขวา:** สั่งให้ระบบรีเฟรชข้อมูลโทเคนและโควต้าใหม่ทันที
- **คีย์ลัดรีเฟรชหน้าต่าง:** กด `Ctrl + Shift + P` แล้วเลือก `Reload Window` เพื่อโหลด UI ใหม่โดยไม่ต้องปิดแอป
